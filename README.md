# ציד היהלומים · Diamond Run

משחק ריצה אינסופי בתלת־ממד. אתה יהלום בליטוש בריליאנט שטס במנהרת זהב — אוסף אבנים, חומק ממכשולים, ומקבל בונוס על חליפה צמודה.

**[שחק עכשיו →](https://dnealnral2017-ctrl.github.io/diamond-run/)**

## איך משחקים

| פעולה | שליטה |
|---|---|
| היגוי | עכבר, אצבע, חיצים או `WASD` |
| השהיה | `P` או `Esc` |

- **יהלום** — ניקוד. אבנים רצופות בונות קומבו עד ×10.
- **חליפה צמודה** — עברת מכשול במרווח של פחות מיחידה בלי להיפגע: 120 נקודות.
- **שלושה חיים.** מגן סופג פגיעה אחת.

## מכשולים

נפתחים בהדרגה לפי ניקוד, בחמישה שלבים:

1. **מנהרת הזהב** — להבים מסתובבים
2. **שער הפלדה** — טבעות שצריך לעבור דרכן, זזות מהמרכז
3. **יער העמודים** — שלושה עמודים עם מעבר צר
4. **המכבש** — שני לוחות שנפתחים ונסגרים בקצב
5. **הליבה** — הכול יחד, במהירות מלאה

## טכני

קובץ HTML יחיד, ללא תהליך בנייה. `index.html` הוא המשחק כולו.

- **Three.js r169** דרך import map (unpkg)
- **UnrealBloomPass** — עוצמת הבלום עולה עם הקומבו
- **PMREM** ממפת סביבה פרוצדורלית שנבנית בקנבס — זה מה שנותן לזהב החזרי אור אמיתיים
- **חומר יהלום** — `transmission` עם IOR 2.42 ו־`flatShading` לפאות
- זיהוי פגיעה אנליטי לכל סוג מכשול (מרחק זוויתי מזרועות להב, רדיוס לשער, וכו'), ולא תיבות גבול
- Object pooling לכל המכשולים, היהלומים והחלקיקים — אפס הקצאות בלולאה
- שיא נשמר ב־`localStorage`

הרצה מקומית:

```bash
python3 -m http.server 8000
# http://localhost:8000
```
